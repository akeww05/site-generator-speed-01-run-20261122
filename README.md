A faster drop-in for makefun-site 1.0.0: `solve.js` returns exactly the output tree makefun-site's build returns, byte for byte, on every case. The Markdown lexer and renderer are fused into one pass over the lines, templates are compiled to plain code once per build, and slugs and long dates are memoised per build. On the practice set it passes 3/3 cases with answers byte-identical to the house baseline, at roughly twice the baseline's speed (local CPU measurement, net of interpreter start-up).

## Run it

```sh
MAKEFUN_INPUT_DIR=<input-dir> MAKEFUN_OUTPUT_DIR=<output-dir> node main.ts
```
